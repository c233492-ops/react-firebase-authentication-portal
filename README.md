## Project Overview

AuthPortal is a responsive web application developed using React and Firebase Authentication. It allows users to register, log in, access a protected dashboard, and view their profile.

## Features

- User Registration with Email and Password
- User Login and Logout
- Firebase Authentication
- Protected Dashboard
- Profile Page
- React Router Navigation
- Responsive User Interface

## Technologies Used

- React
- JavaScript
- Vite
- Firebase Authentication
- React Router DOM
- CSS
- npm

## Project Structure

- `src/components/` – Reusable components and protected routes
- `src/context/` – Authentication context
- `src/pages/` – Home, Login, Register, Dashboard and Profile
- `src/firebase.js` – Firebase configuration
- `src/App.jsx` – Application routes
- `src/main.jsx` – Application entry point

## Installation and Setup

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite in your browser.

## Authentication

Firebase Authentication is used to register and authenticate users. Private pages are protected so unauthenticated users cannot directly access the dashboard.
